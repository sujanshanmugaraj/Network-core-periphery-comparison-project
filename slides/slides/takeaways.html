Three takeaways. If you only need a ranking of nodes, the k-core is enough — it matches cohesion levels almost perfectly at linear cost. If you care about how the core is organised, compute cohesion: a k-core can be a federation of cohesive groups. And if you care about vulnerability, the brokers between those groups are where to look. Limitations: eight networks, static attacks, unweighted undirected graphs, and a null model that preserves degrees but not clustering. Future work: an adaptive version of brokerage, weighted cohesion, and clustering-preserving null models.
