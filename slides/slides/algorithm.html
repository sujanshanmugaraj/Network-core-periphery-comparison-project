An exact, fast k-component algorithm

1 · Split safely

Prune to the k-core, find any vertex cut of size < k, recurse on each side plus the cut. No k-component can be lost.

2 · Certify cheaply

k common neighbours, or a “bootstrap closure” from a node, prove k disjoint paths without max-flow (Lemma 1).

3 · Flow the rest

Remaining pairs: unit-capacity max-flow on the node-split graph, compiled with Numba, cut-off at k.

A methods contribution we did not plan. NetworkX's k_components is the standard tool, but on Les Misérables it returns a 32-node 3-component that sits strictly inside a 3-connected 34-node set, so it is not maximal. We wrote an exact algorithm. Splitting along any cut smaller than k is safe because a k-component cannot be disconnected by fewer than k nodes. Most connectivity checks are certified without max-flow using common neighbours or a bootstrap-percolation-style closure, which is proven in Lemma 1. The rest uses a fast Numba max-flow. Facebook takes 83 seconds; before our flow code it did not finish in 30 minutes.
